# Homebrew tap for Roundhand

[Roundhand](https://roundhand.dev/) is dictation for the Mac: speak into any app and it writes clean text formatted for where it lands. Speech recognition runs on your Mac.

## Install

```
brew install --cask avisangle/roundhand/roundhand
```

Requires macOS 14 or later on Apple silicon. Roundhand updates itself through its built-in updater, so `brew upgrade` is not needed.

## Uninstall

```
brew uninstall --cask roundhand          # the app only
brew uninstall --zap --cask roundhand    # the app and its settings, history and models
```
